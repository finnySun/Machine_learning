# Machine Learning 課程筆記

此 repository 收錄機器學習課程的 Jupyter Notebook，依課程階段整理：

- `Step1_Introduction_to_Data_Processing`
- `Step2_Build_a_machine_learning_model`
- `Step3_Advanced_AI_Concepts`
- `Step4_Project_Implementation`

## 在另一台電腦使用

1. 安裝 Git、Python 和 VS Code，並在 VS Code 安裝 Python 與 Jupyter 擴充套件。
2. 在 VS Code 終端機執行 `git clone <GitHub repository 網址>`，再開啟下載的資料夾。
3. 開啟 `.ipynb` 檔案，選擇本機 Python interpreter/kernel 執行。

`.venv` 等本機環境檔不會上傳；在新電腦上需自行建立 Python 環境並安裝 Notebook 所需套件。
